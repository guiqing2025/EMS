# 订单催办阶段与责任人（填写版）

> 用途：把「从接单到结案」拆成固定阶段；你填写**责任账号**和**催办时限**后，系统按此催人做事。  
> 说明：本文件只定规则，**不改生产扫码写路径**。扫码卡控仍按现有工序规则执行。  
> 填写人：对话逐项确认中　日期：2026-08-10　版本：v0.2

---

## 一、怎么填

1. **责任账号**：写登录用户名（可多人，逗号分隔）。系统催办会推给这些人。
2. **升级账号**：超时未处理时加催/抄送的人（可填主管）。
3. **完成标准**：可改表述；最终以你签过的为准。
4. **时限**：建议填「进入本阶段后 X 小时/天内必须完成」，超时进升级。
5. 某阶段对本厂不适用：在「启用」列写 `否`。

系统内置角色仅供参考（账号仍由你指定到人）：


| 角色 key              | 常见含义       |
| ------------------- | ---------- |
| admin               | 管理员        |
| planner             | 计划         |
| pmc                 | PMC        |
| engineering / eng_* | 工程         |
| warehouse           | 仓库         |
| laser               | 镭雕         |
| 产线账号                | 按线体/班组实际账号 |

## 二、总览（阶段流水）

```
S0 新单入库
 → S1 待工程齐套
 → S2 待物料齐料
 → S3 待 PMC 排计划
 → S4 待产线开工
 → S5 在制生产（过站）
 → S6 待包装入库
 → S7 待发货
 → S8 待结案
 → S9 已结案（清理/禁止回灌）
```

并行说明：

- **S1 工程** 与 **S2 齐料** 可并行；**两者都完成后**才进入 S3 催排产。
- **S5 在制** 内部仍走扫码卡控（SMT-AOI→插件→后焊→ICT→三防…），本表管「催进度」，不改枪序。
