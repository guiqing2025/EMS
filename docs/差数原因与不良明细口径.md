# 订单工作台 · 差数原因与不良明细口径

> 只读展示，**不改** `/api/process-scan`、`/api/packing/scan`、PDA 写路径。  
> 日期：2026-08-10

## 差数原因 code

| code | 含义 |
|--|--|
| `not_tested` | 相对订单数量，AOI/ICT 尚未测试到的数量 |
| `not_scanned` | 本站尚未过站/入库扫码 |
| `waiting_upstream` | 受上站差数限制（上站差多少，本站最多解释多少） |
| `aoi_fail` | AOI 不良说明（已测通常计入进度，不等于差数本身，可能卡后站） |
| `ict_fail` | ICT 不良说明（同上） |

## 不良明细

- 来源：本采购单 AOI / ICT 热表（+归档合计）；FAIL/FALL/NG
- 工作台默认带一小批不良板码；完整列表仍可用订单列表抽屉

## 未完成编码 / 不良编码

| 列表 | 规则 |
|--|--|
| 未完成编码 | 有镭雕登记时：应有码 − 本站已过码；后站资格池为上站 PASS/已过集合 |
| 不良编码 | AOI/ICT 的 FAIL/FALL/NG 板码 |
| 列不出时 | 无镭雕范围等 → 只显示说明，不强行编造板码 |
| 上限 | 单站列表默认最多约 300 条，超出截断提示 |

## 交互

工序进度行可点击（有差数/未完成/不良时）→ 抽屉展示原因 + **未完成编码** + **不良编码**。
