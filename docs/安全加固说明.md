# 安全加固说明

已在生产入口（本机 `:8000`，地址以 `EMS_PUBLIC_URL` 或启动探测为准）启用：

1. **关闭** `/docs`、`/redoc`、`/openapi.json`（对外 404）
2. **未登录访问 API** → 统一 `401 请先登录系统`（ICT 闸道除外，需 `X-Api-Key`）
3. **限流**：登录约 20 次/分钟/IP；普通 API 600；ICT 闸道 300（可在 `srm_config.json` → `security` 调整）
4. **CORS** 仅允许本机/局域网常用前端源（同配置项 `cors_origins`）
5. **常见探测路径**（`.env`、`.git`、`wp-admin` 等）直接 404
6. **异常不回堆栈**；响应带基础安全头

产线网页登录后扫码、ICT 闸道带 Key，行为与加固前一致。
